Web-программалау. Web-сайт туралы түсінік

Веб-бет пен веб-сайттың айырмасын түсіну.

Веб-бет — браузер көрсететін жеке құжат. Веб-сайт — ортақ мақсатпен байланысқан беттер жиыны. Мысалы, мектеп сайтының басты беті, жаңалықтары және байланыс беті болады.

02 · HTML
HTML тіліне кіріспе. HTML құжатының құрылымы
HTML файлын дұрыс құрып, браузерде ашу.
HTML (HyperText Markup Language) — гипермәтіндік белгілеу тілі. Ол есептеу алгоритмін жазбайды: мәтіннің қай бөлігі тақырып, азатжол, сурет не сілтеме екенін белгілейді. Файл кеңейтілімі — .html немесе .htm.
<p>Менің алғашқы азатжолым.</p>Ашылатын тегМазмұнЖабылатын тег
Көп элемент ашылатын және жабылатын тегтен тұрады. Жұпсыз элементтерде жабылатын тег болмайды: img, br, hr, meta, link. Атрибут ашылатын тегте жазылады: мысалы, lang="kk".

03 · HTML
HTML-де қаріптің өлшемін, түсін және түрін белгілеу
Мәтін құрылымын белгілеп, қаріпті CSS-пен өзгерту.
h1–h6 — тақырып деңгейлері; p — азатжол. Деңгейді мәтіннің мағынасына қарай таңда: ең үлкен қаріпті таңдау үшін ғана h1 қолданба. strong — маңызды мәтін, em — екпін, sub және sup — төменгі және жоғарғы индекс.
font-size өлшемді, color түсті, font-family қаріп отбасын береді. Түсті атаумен, HEX немесе RGB мәнімен жазуға болады: red, #ff0000, rgb(255, 0, 0).
Оқулықтағы font, basefont және bgcolor — ескі безендіру тәсілдері. Жаңа мысалдарда олардың орнына CSS қолданамыз. br жаңа жолға өткізеді, жаңа азатжол жасамайды.
Тізім үшін ul (маркерленген) немесе ol (нөмірленген), әр тармақ үшін li жазылады. dl — ұғымдар тізімі, оның dt элементі атауды, dd түсіндірмені береді.

05 · HTML
HTML құжатына графикалық кескіндерді енгізу
Суретті файл жолы және балама мәтін арқылы қосу.
img суретті көрсетеді. src — файлдың жолы, alt — оның мағынасын түсіндіретін балама мәтін. alt мәтінін экран оқу құралдары пайдаланады және сурет жүктелмесе көрсетілуі мүмкін; қалқымалы кеңес үшін title қолданылады.
Сурет HTML-мен бір бумада болуы міндетті емес. Мысалы, images/alatau.svg ішкі бумадағы файлды көрсетеді. JPG, PNG, GIF, SVG және WebP секілді форматтар қолданылады.
width пен height бастапқы өлшемдерге сай берілгені дұрыс. CSS-тегі max-width: 100% және height: auto пропорцияны сақтайды. Фондық сурет үшін CSS background-image пайдаланылады.

06 · HTML
HTML тілінде кесте құру
Деректерді қатарлар мен бағандарға бөлу.
table — кесте; tr — қатар; th — тақырып ұяшығы; td — дерек ұяшығы. caption атауды, thead тақырып қатарларын, tbody негізгі деректерді біріктіреді.

Кестені деректер үшін қолдан. Беттің жалпы орналасуын кестемен жасамаймыз. Шекара, түс, ені және ұяшық аралығы CSS қасиеттерімен реттеледі: border, background, width, padding, border-collapse.

08 · CSS
Каскадты стильдер кестесі — CSS
Стильді HTML-ден бөлек файлға шығарып қолдану.
CSS (Cascading Style Sheets) — құжаттың сыртқы көрінісін сипаттайтын тіл. Бір style.css файлын бірнеше HTML бетке қосуға болады. Қаріп не түс өзгерсе, ортақ ережені бір жерден түзетесің.
h1{color:#7354ae;}СелекторҚасиетМән
Ереже селектордан және фигуралы жақшадағы жариялаулардан тұрады. Әр жариялау қасиет: мән; түрінде жазылады. Бірнеше қасиет нүктелі үтірмен бөлінеді.
Стильді style атрибутымен, head ішіндегі style элементімен немесе сыртқы CSS файлымен қосуға болады. Осы оқулықта көбіне сыртқы файлды қолданамыз: <link rel="stylesheet" href="style.css">.

09 · CSS
CSS селекторларының түрлері
Элемент пен класс бойынша қажетті бөліктерді таңдау.
Селектор — ереже қай элементтерге қолданылатынын анықтайтын үлгі. p барлық p элементін, .note note класы бар элементтерді, p.note осы кластағы p элементтерін таңдайды.
Бір class мәні бірнеше элементте қайталана алады. Бір элементте бірнеше класс болуы да мүмкін: class="note large". h1, h2 — екі селекторға ортақ ереже; * — барлық элемент.
Бір қасиетке бірнеше ереже сәйкес келсе, каскад олардың басымдығын анықтайды. Осы қарапайым мысалдарда id селекторы кластан, класс элемент селекторынан нақтырақ. Басымдығы тең ережелерде кейін жазылғаны жеңеді.

10 · CSS
Идентификаторлы және контекстік селекторлар
Бірегей элементті және ішкі элементтерді дәл таңдау.
#pink id="pink" элементін таңдайды. Бір бетте көптеген id болуы мүмкін, бірақ бір мән екі элементке берілмейді. body сөзін id ретінде қолдануға тыйым жоқ; түсінікті атаулар таңдаған дұрыс.
p strong — p ішіндегі strong элементтері. Бос орын ұрпақтық қатынасты білдіреді: арада басқа элемент тұрса да сәйкес келеді. p > strong тек тікелей баланы таңдайды.
id үшін #, класс үшін нүкте, ішкі контекст үшін бос орын қолданылады. Мысалдағы сыртқы strong түсінің өзгермегенін салыстыр.

11 · CSS
Практикалық жұмыс: веб-сайттың дизайнын жасау
HTML бетті толық безендірілген шағын жобаға айналдыру.
Алғашқы парағыңды безендір: үйлесімді фон, оқылатын қаріп, үлкен тақырып, сілтеме-батырма және оқу жоспары бар карточка жаса. Сурет экран еніне бейімделсін.
HTML құрылымын index.html ішінде, дизайнды style.css ішінде сақта. padding, margin, border және border-radius мәндерін өзгертіп, әр өзгерістің нәтижесін салыстыр. Дайын мысалды бірден ашпай, алдымен өз шешіміңді ойластыр.

12 · JAVASCRIPT
JavaScript тіліне кіріспе. Скриптерді қолдану
Батырма мен енгізу өрісіне қарапайым әрекет қосу.
JavaScript — программалау тілі. Браузерде ол элементтердің мәтінін, стилін және әрекетін өзгерте алады. Ол браузерден тыс ортада да қолданылады. HTML құрылымды, CSS көріністі, JavaScript әрекетті басқарады.
Скриптті script элементіне жазуға не сыртқы script.js файлы арқылы қосуға болады. Мысалдарда скрипт body соңына орналастырылған: оған дейін батырмалар мен азатжолдар құрылып үлгереді. head ішінде қосылса, сыртқы скриптке defer атрибутын қолдануға болады.
querySelector() элементті табады, addEventListener() оқиғаны тыңдайды, textContent мәтінді өзгертеді. Функция атауын өңдегішке жақшасыз береміз: salem; salem() оны бірден шақырар еді.
ОқиғаҚай кезде орындалады?
click / dblclickБір рет / екі рет шерту
inputӨрістегі мән өзгергенде
focus / blurФокус алынғанда / жоғалғанда
keydown / keyupПерне басылғанда / босатылғанда
mouseover / mouseoutКөрсеткіш элементке кіргенде / шыққанда
mousedownТінтуір батырмасы басылғанда
submitПішінді жіберу әрекетінде
loadБет және ресурстар жүктелгенде
Қазіргі HTML-де script үшін language="javascript" және ескі түсіндірме қоршауы қажет емес. Бұл мысалдар оқиғаны addEventListener арқылы қосады.
